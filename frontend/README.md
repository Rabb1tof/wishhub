# WishHub frontend

React, TypeScript и Vite. Установка: `npm ci`; разработка: `npm run dev`; проверка типов и сборка: `npm run build`; линтер: `npm run lint`. Тестовая команда указана в package.json.

Карточка содержит обязательные URL и имя, необязательные фото/цену, редактирование и очистку значений. Получение метаданных запускается только кнопкой; сохранение работает независимо от него. Поздние ответы для другой ссылки не применяются, ручные правки не затираются.

Клиент получает плоский WishlistItem DTO. Изображения загружаются напрямую с URL, с lazy-loading, no-referrer и заглушкой при ошибке. Polling фоновой обработки и настройка расписания цен отсутствуют.

Запросы API идут через существующий typed client. Один сценарий используется сайтом и будущим Telegram Mini App; фактический Telegram WebView требует отдельной квалификации при его реализации.
