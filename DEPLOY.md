# Развёртывание WishHub

Рекомендуемый путь — [готовые GHCR-образы](DEPLOY-OPTIMIZED.md). Состав: API, frontend, PostgreSQL; браузерные процессы, Redis и фоновые задачи товаров отсутствуют.

Для сборки на сервере заполните `.env.example`, поместите сертификат `fullchain.pem` и ключ `privkey.pem` в `./ssl` (не добавляйте их в Git) для `nginx.conf`, затем используйте `docker-compose.prod.yml`. Файлы Compose не выпускают TLS-сертификаты самостоятельно.

При обновлении старой установки сначала выполните [переход и резервное копирование](docs/lightweight-rollout.md). API применяет миграции при запуске. API и frontend обновляются совместно; проверьте `/health` и создание карточки только с URL+именем. Сохраните PostgreSQL и аватары; не используйте `down -v`.

Для запуска без контейнеров задайте ASP.NET-конфигурацию из [CONFIGURATION.md](CONFIGURATION.md), запустите API под существующим менеджером процессов, соберите frontend и направьте reverse proxy на API и статические файлы. Сохраните маршруты `/api`, `/hubs`, `/avatars`. Дополнительная установка браузера не требуется.

Отдельный prod Compose перенаправляет порт80 на HTTPS443; nginx передаёт SPA в frontend:80, запросы API — в api:5000. Сертификаты должны существовать заранее. Для EasyPanel/Traefik используйте registry Compose: там TLS завершает внешний ingress.

Обновите API и frontend совместно и перезагрузите открытые вкладки. Новый клиент использует курсор истории и `/api/messages/{userId}/read-batch`. Завершение входа VK использует одноразовый HttpOnly cookie и `POST /api/auth/complete`. Укажите публичный HTTPS-адрес в Frontend__Url. После смены пароля refresh-сессии отзываются и требуется новый вход; уже выданный access token действует до настроенного срока JWT.
